# «نسخة الآن» لا تتكرّر (فرع backup-dedupe، من main)
- run.sh: الخادم الحالي (main) والجديد، تخزين النسخ وقاعدة البيانات في الذاكرة: 4 طلبات متطابقة = نسخة واحدة، إعادة المحاولة بالمعرّف نفسه لا تنشئ نسخة، طلب مكرّر أثناء نسخ جارٍ = «قيد الإنشاء»، التطبيق القديم بلا معرّف: نسخة واحدة خلال دقيقتين، النسخ الموجودة والحسابات لم تتغيّر.
- browser.js (أداة ftest، حساب المشرف): ضغطات سريعة، إعادة رسم الصفحة أثناء النسخ، إعادة المحاولة بعد خطأ بالمعرّف نفسه.
- القائمة تعرض وقت النسخة بالثواني وآخر أرقام مفتاحها.
