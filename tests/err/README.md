# حماية /err (فرع err-guard)
- run.sh: التنقية (sanitize.mjs) وبوّابة الأخطاء (gate.mjs) بشيفرة الخادم الحقيقية، وكائن دائم مُحاكى بـSQLite (dostub.mjs)، وقاعدة في الذاكرة مع حقن أعطال. نحو 15 ثانية.
- run-workerd.sh: الخادم نفسه في محرّك Cloudflare الحقيقي محليًا (Miniflare/workerd) بتخزين SQLite ومنبّهات حقيقية، وFirestore مزيّف يُعترَض كل اتصال إليه. نحو دقيقتين. يحتاج Miniflare في ~/.cache/muf-miniflare وإلا «لم تُشغَّل».

## حدود التنقية (ليست ضمانًا كاملًا لإزالة البيانات الشخصية)
تُزال أنماط محددة فقط: رموز الدخول (eyJ… وما بعد Bearer)، وعناوين البريد، ومعرّفات الحسابات داخل مسارات المجموعات (users/… وغيرها) أو بعد uid=،
ومعاملات الروابط ما عدا v=، وما بعد # إن لم يكن اسم صفحة قصيرًا.
لا تكتشف الأسماء الشخصية ولا أي نص حرّ آخر داخل الرسالة، ولا معرّفات بصيغ أخرى. وصف الجهاز يُحفظ كما هو، ومعرّفات المستخدمين المتأثرين
تبقى في وثيقة الخطأ (للمشرف وحده) ولا تدخل الملخّص. كل وثيقة تحمل حقل san بأنواع ما نُقّي وعدده.
