# الاختبارات
كلها محلية: لا شبكة ولا مفاتيح ولا بيانات حقيقية، ولا تكتب في أي قاعدة حقيقية.

- `run-all.sh`: يشغّل كل مجموعات سطر الأوامر ويطبع ملخّصًا (نحو 6 دقائق). يفشل إن فشلت أي مجموعة.
- `BASE`: النسخ المرجعية بدل origin/main:
  - `PRE_FOLD`: نسخة ما قبل الطيّ ونقطة الحفظ، يُبنى منها «المرجع بلا قصّ» في rewards وcheckpoint. ثابتة.
  - `RELEASED`: آخر نسخة منشورة. تُحدَّث يدويًا بعد كل نشر، في إيداع مستقل.
- `lib.sh`: دوال مشتركة. كل مجموعة تفشل إن ظهر سطر FAIL أو لم يُنفَّذ أي فحص.
- إن كانت RELEASED مطابقة للشيفرة الحالية (كما على main بعد النشر) تُطبع «المقارنة غير فعّالة»: ليس فشلًا،
  لكن فحوص «قديم مقابل جديد» عندها لا تقارن شيئًا، والضمان يأتي من الفحوص المطلقة.
- `golden/`: نتائج متوقَّعة ثابتة محسوبة يدويًا من قواعد التطبيق (المراجعة المتباعدة، الخبرة، الجواهر، المستوى،
  منع التكرار، حراسة الخادم، الطيّ). لا تقارن نسختين، فتكشف الخطأ ولو دخل النسختين معًا.
- اختبارات المتصفّح (stage0 وui-tweaks وbrowser*.js) وcheckpoint/integration.mjs وlog-at-cap-bug.mjs لا يشغّلها run-all.
