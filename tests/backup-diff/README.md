# فروق «تحقق كامل» (فرع backup-inspect، من main)
- run.sh: سيناريو بشيفرة الخادم الحالية: أحداث بقيت في هاتف متعلّم، ثم نسخة، ثم مزامنة متأخرة → فروق في حسابه وحده، والأدلة من الملف (وقت النسخة، وقت آخر كتابة لوثيقته، أوقات المحطات). 11 فحصًا.
- inspect.sh ملف1.json.gz [ملف2.json.gz]: يفحص ملفات نسخ حقيقية منزَّلة دون أي اتصال ودون كتابة: ملخّص كل حساب بشيفرة الخادم نفسها، وآخر كتابة لوثيقته، وأوقات محطاته، والفرق بين نسختين ومتى حدث.
- browser.js: «تحقق كامل» يذكر وقت النسخة ومفتاحها ووقت قراءة الحالة، ويعرض جدولي النسخة والآن مع تلوين الفروق. 3 فحوص.
