# «آخر ظهور» (فرع seen-fix)
- السبب: «آخر ظهور» كان وقت آخر نبضة من التطبيق، والنبضة تُرسل كل دقيقة (أو كل 3 ثوانٍ لمن له أصدقاء) ما دام التطبيق مفتوحًا وظاهرًا، ولو لم يلمسه أحد، وكذلك عند كل فتح أو إعادة تحميل.
- الإصلاح: النبضة تحمل act=1 فقط إن لمس المتعلّم الشاشة أو كتب منذ النبضة السابقة، والخادم يحفظه في on/{uid}.a. «آخر ظهور» = a، وللتطبيق القديم الذي لا يرسله t كما كان. «متصل الآن» يبقى على t.
- النص: بالدقائق في الساعة الأولى، ثم «اليوم/أمس الساعة hh:mm»، ثم بالأيام؛ بلا تقريب إلى الأعلى.
- run.sh: الخادم القديم والجديد (12 فحصًا). browser.js: في الصفحة (12 فحصًا).
